# 🇦🇺 小さな子どもと暮らす メルボルン20日間滞在ハンドブック（サウス・ヤラ編）

メルボルンで小さな子ども（幼児〜未就学児）連れで20日間滞在するご家族のための、スマートフォン最適化Web生活ナビゲーションです。

## 📍 滞在拠点
- **住所**: `10B Surrey Road, South Yarra, VIC 3141`
- **エリア特徴**: メルボルン屈指の高級住宅街・サウス・ヤラ（South Yarra）。
  - **サウスヤラ駅**: 快速電車でCBD（フリンダース駅）までわずか5〜7分
  - **プラーラン市場（Prahran Market）**: 徒歩6分。新鮮な果物、焼きたてパン、中庭キッズプレイエリア
  - **トラム網**: トラム72番（都心 Swanston St直通）、トラム78番（セントキルダ海辺直通）、トラム58番（王立植物園・動物園・小児病院直通）
  - **公園・遊び場**: 目の前にSurrey Road Park（滑り台・遊具）、近隣に広大なFawkner Park、王立植物園イアン・ポッター子ども庭園
  - **医療安心**: 徒歩12分/トラムすぐのThe Alfred総合病院救急（24h ER）、トラム58番直通のロイヤルチルドレンズ小児専門病院（RCH）

1. **Googleマップ連携**: 宿泊先ピンの表示＆外出先からの帰り道ナビゲーションをワンタップ起動

   - ③ 都心放射状アクセス（電車5分で都心フリンダース駅、トラム路線網）
   - ④ サウスヤラ徒歩生活圏（Surrey Rd、チャペル通り、プラーラン市場、遊具公園）
3. **周辺ストリートビュー＆施設ガイド**:

   - スーパー買い出し（Coles, Woolworths, Big W子ども服・おもちゃ）、ベビーチーノ名店
