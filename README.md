# Melbourne Family Living Guide (20-Day Extended Stay)
## 小さな子どもと暮らすメルボルン20日間滞在のしおり（スマホ最適化Webアプリ）

宿泊拠点：**Flemington Road（ノース・メルボルン / パークビル境界）**

スマートフォンで快適に閲覧・操作できるモバイルWebページです。

### 🌟 主な機能・特徴
- **📱 スマホ完全最適化**: 親指でタップしやすいボトムナビバー、横スクロールカテゴリバー
- **🗺️ 4段階マルチスケール地図**: 大陸 ➔ 都市圏 ➔ アクセス ➔ 生活圏のベクター図解（拡大しても文字が一切ぼやけません）
- **📍 ワンタップ Google Maps 連携**: 遊び場、スーパー、病院、観光スポットへのナビが即座に起動
- **📞 ワンタップ緊急通報・電話発信**: `000`、小児病院ER、日本総領事館への直通通話
- **✅ 保存機能付き持ち物チェックリスト**: タップしたチェック状態がスマホ内に自動保存
- **🖼️ 街並み・ストリートビュー・施設写真**: 30枚以上の高解像度写真を掲載
